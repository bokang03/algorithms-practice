# [Programmers] 멀리 뛰기 (Level 2) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 2)
* **권장 풀이 시간:** 20분
* **핵심 키워드:** 다이나믹 프로그래밍(DP), 피보나치 수열(Fibonacci), 점화식

---

## 2. 문제 설명
효진이는 멀리 뛰기를 연습하고 있습니다. 효진이는 한 번에 **1칸** 또는 **2칸**을 뛸 수 있습니다. 

멀리 뛰기에 사용될 칸의 개수 `n`이 주어질 때, 효진이가 끝까지 도달하는 **방법의 가짓수**를 구하는 프로그램을 작성해야 합니다.

단, 최종 결과는 방법의 가짓수를 **1,234,567로 나눈 나머지**를 반환해야 합니다.

---

## 3. 해결 전략 및 점화식
이 문제는 대표적인 **다이나믹 프로그래밍(DP)** 유형으로, 피보나치 수열과 동일한 원리로 동작합니다.

* **1칸에 도달하는 방법 ($DP[1]$):** `(1)` $\rightarrow$ **1가지**
* **2칸에 도달하는 방법 ($DP[2]$):** `(1+1)`, `(2)` $\rightarrow$ **2가지**
* **3칸에 도달하는 방법 ($DP[3]$):**
  * 2칸 위치에서 1칸을 뛰는 경우 ($DP[2]$의 가짓수)
  * 1칸 위치에서 2칸을 뛰는 경우 ($DP[1]$의 가짓수)
  * 따라서 $DP[3] = DP[2] + DP[1] = 2 + 1 = 3$가지

### 💡 점화식
> **$DP[n] = (DP[n-1] + DP[n-2]) \pmod{1,234,567}$**

* ⚠️ **주의사항:** 오버플로우를 방지하기 위해 계산 중간 과정마다 `1,234,567`로 나눈 나머지를 저장해야 합니다.

---

## 4. 제한 사항
* `n`: 1 이상 2,000 이하의 자연수

---

## 5. 입출력 예시

| n | result |
| :--- | :--- |
| **4** | **5** |
| **3** | **3** |

### 입출력 예 설명

* **첫 번째 예시 (`n = 4`)**
  * 1칸 또는 2칸을 뛰어 4칸에 도달하는 방법:
    1. `(1, 1, 1, 1)`
    2. `(1, 1, 2)`
    3. `(1, 2, 1)`
    4. `(2, 1, 1)`
    5. `(2, 2)`
  * 총 **5가지** 방법이 있으므로 5를 반환합니다.

* **두 번째 예시 (`n = 3`)**
  * 1칸 또는 2칸을 뛰어 3칸에 도달하는 방법:
    1. `(1, 1, 1)`
    2. `(1, 2)`
    3. `(2, 1)`
  * 총 **3가지** 방법이 있으므로 3을 반환합니다.
