# [Programmers] [PCCE 기출문제] 9번 / 이웃한 칸 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 20분
* **핵심 키워드:** 2차원 배열(2D Array), 탐색(Search), 4방향 이동(Delta Search), 조건문

---

## 2. 문제 설명
각 칸마다 색상이 칠해져 있는 2차원 격자 모양의 지도가 있습니다. 2차원 정수 리스트 `board`와 특정 칸의 위치를 나타내는 두 정수 `h`, `w`가 주어집니다.

선택한 칸 `board[h][w]`와 **상, 하, 좌, 우로 이웃한 칸들 중 같은 색깔이 칠해져 있는 칸의 개수**를 구하는 프로그램을 작성해야 합니다.

---

## 3. 알고리즘 수행 과정
문제에서 제시한 의도에 따라 다음과 같은 순서로 로직을 구현합니다.

1. 정수를 저장할 변수 `n`을 입력받은 `board`의 길이로 초기화합니다.
2. 같은 색으로 칠해진 칸의 개수를 세기 위한 변수 `count`를 `0`으로 초기화합니다.
3. 상, 하, 좌, 우 변화량을 나타내는 배열 `dh`와 `dw`를 정의합니다.
   * `dh = [0, 1, -1, 0]`
   * `dw = [1, 0, 0, -1]`
4. `i` 값을 `0`부터 `3`까지 1씩 증가시키며 반복합니다.
   * 체크할 이웃 칸의 좌표 `h_check = h + dh[i]`, `w_check = w + dw[i]`를 구합니다.
   * `h_check`가 `0` 이상 `n` 미만이고, `w_check`가 `0` 이상 `n` 미만인지 검사합니다. (배열 범위를 벗어나지 않는지 확인)
   * 조건에 맞다면 `board[h][w]`의 값과 `board[h_check][w_check]`의 값이 같은지 비교합니다.
   * 값이 같다면 `count`를 `1` 증가시킵니다.
5. 최종 `count` 값을 반환합니다.

---

## 4. 제한 사항
* `board`는 정사각형 모양의 2차원 리스트입니다.
* `board`의 길이: 1 이상 7 이하
* `board`의 원소(색상 이름): 알파벳 소문자로만 이루어진 길이 1 이상 10 이하의 문자열
* `h`, `w`: 0 이상 `board`의 길이 미만인 정수

---

## 5. 입출력 예시

| board | h | w | result |
| :--- | :--- | :--- | :--- |
| `[["blue", "red", "orange", "red"], ["red", "asdf", "blue", "orange"], ["orange", "blue", "red", "blue"], ["white", "orange", "blue", "red"]]` | 1 | 1 | **0** |
| `[["yellow", "green"], ["green", "yellow"]]` | 0 | 0 | **1** |

### 입출력 예 설명

* **첫 번째 예시 (`h = 1, w = 1`)**
  * `board[1][1]`의 색상은 `"asdf"`입니다.
  * 상(`board[0][1]`: `"red"`), 하(`board[2][1]`: `"blue"`), 좌(`board[1][0]`: `"red"`), 우(`board[1][2]`: `"blue"`) 중에서 `"asdf"`와 같은 색상은 없으므로 **`0`**을 반환합니다.

* **두 번째 예시 (`h = 0, w = 0`)**
  * `board[0][0]`의 색상은 `"yellow"`입니다.
  * 이웃한 칸인 우(`board[0][1]`: `"green"`), 하(`board[1][0]`: `"green"`) 중 같은 색상은 없으나, `board[1][1]`은 대각선 위치이므로 포함되지 않습니다.
  * 만약 `h = 0, w = 1` 칸이라면 아래쪽(`board[1][1]`)과 같은 색상이므로 **`1`**이 됩니다.
