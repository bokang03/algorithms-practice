# [Programmers] 숫자 짝꿍 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 30분
* **핵심 키워드:** 문자열(String), 해시/빈도수(Frequency Map), 정렬/그리디(Greedy)

---

## 2. 문제 설명
두 개의 크게 긴 정수 `X`와 `Y`가 주어질 때, 두 수의 공통으로 나타나는 정수 임의의 자리수들을 이용하여 만들 수 있는 가장 큰 정수를 **"숫자 짝꿍"**이라고 합니다.

두 수의 짝꿍을 구하여 문자열로 반환하는 함수를 완성해야 합니다.

### 상세 규칙 및 예외 사항
* **공통된 숫자 조합:** `X`와 `Y`에 공통으로 존재하는 숫자가 있는 경우, 그 숫자들을 조합하여 만들 수 있는 **가장 큰 정수**를 구해야 합니다. (즉, 공통 숫자를 내림차순으로 정렬하여 이어 붙여야 함)
* **짝꿍이 존재하지 않는 경우:** 공통으로 나타나는 숫자가 없다면 짝꿍은 존재하지 않으며, 이 경우 문자열 `"-1"`을 반환합니다.
* **0만 공통으로 존재하는 경우:** 짝꿍이 오직 `"0"`으로만 구성되어 있다면 (예: 공통된 숫자가 `0, 0`인 경우), `"00"`이 아니라 실제 숫자 `"0"` 하나만 반환해야 합니다.

---

## 3. 제한 사항
* `X`, `Y`는 3,000,000자리 이하의 매우 긴 숫자 문자열입니다.
* 숫자 문자열의 첫 자리가 `0`일 수도 있으며, 중간에 `0`이 여러 개 포함될 수도 있습니다.
* 데이터의 크기가 매우 크기 때문에 문자열 전체를 완전 탐색($O(N^2)$)하거나 실제로 무거운 객체를 정렬하는 대신, 각 숫자의 빈도수(0~9)를 카운팅하는 방식으로 접근해야 합니다.

---

## 4. 입출력 예시

| X | Y | result |
| :--- | :--- | :--- |
| "12321" | "42531" | **"321"** |
| "5525" | "1255" | **"55"** |
| "100" | "2345" | **"-1"** |
| "100" | "203045" | **"0"** |

### 입출력 예 설명
* **첫 번째 예시:** `X`와 `Y`의 공통 숫자는 `1`, `2`, `3`입니다. 이를 조합해 만들 수 있는 가장 큰 수인 `"321"`을 반환합니다.
* **두 번째 예시:** `X`와 `Y`의 공통 숫자는 `5`, `5`입니다. 가장 큰 수인 `"55"`를 반환합니다.
* **세 번째 예시:** 공통 숫자가 전혀 없으므로 `"-1"`을 반환합니다.
* **네 번째 예시:** 공통 숫자는 `0`, `0`입니다. 짝꿍이 0으로만 이루어져 있으므로 `"0"`을 반환합니다.
