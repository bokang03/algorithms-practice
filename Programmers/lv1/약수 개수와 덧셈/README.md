# [프로그래머스] 약수의 개수와 덧셈 - Python3

## 📝 문제 설명
두 정수 `left`와 `right`가 매개변수로 주어집니다. `left`부터 `right`까지의 모든 수들 중에서, 약수의 개수가 짝수인 수는 더하고, 약수의 개수가 홀수인 수는 뺀 수를 return 하도록 solution 함수를 완성해주세요.

---

## ⚠️ 제한사항
- 1 ≤ `left` ≤ `right` ≤ 1,000

---

## 📥 입출력 예
| left | right | result |
| :---: | :---: | :---: |
| 13 | 17 | 43 |
| 24 | 27 | 52 |

---

## 💡 입출력 예 설명

### 입출력 예 #1
- 다음 표는 13부터 17까지의 수들의 약수를 모두 나타낸 것입니다.

| 수 | 약수 | 약수의 개수 |
| :---: | :--- | :---: |
| **13** | 1, 13 | 2 (짝수) |
| **14** | 1, 2, 7, 14 | 4 (짝수) |
| **15** | 1, 3, 5, 15 | 4 (짝수) |
| **16** | 1, 2, 4, 8, 16 | 5 (홀수) |
| **17** | 1, 17 | 2 (짝수) |

- 따라서, $13 + 14 + 15 - 16 + 17 = 43$을 return 해야 합니다.

### 입출력 예 #2
- 다음 표는 24부터 27까지의 수들의 약수를 모두 나타낸 것입니다.

| 수 | 약수 | 약수의 개수 |
| :---: | :--- | :---: |
| **24** | 1, 2, 3, 4, 6, 8, 12, 24 | 8 (짝수) |
| **25** | 1, 5, 25 | 3 (홀수) |
| **26** | 1, 2, 13, 26 | 4 (짝수) |
| **27** | 1, 3, 9, 27 | 4 (짝수) |

- 따라서, $24 - 25 + 26 + 27 = 52$를 return 해야 합니다.

---

## 🔍 한 줄 팁
> 어떤 수가 **제곱수**(예: 1, 4, 9, 16, 25...)이면 약수의 개수가 **홀수**이고, 제곱수가 아니면 약수의 개수가 항상 **짝수**입니다! `int(num**0.5) ** 2 == num` 같은 조건문으로 풀면 훨씬 효율적으로 풀 수 있습니다.
