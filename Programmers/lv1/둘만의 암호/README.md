# [Programmers] 둘만의 암호 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 30분
* **핵심 키워드:** 문자열(String), 시뮬레이션(Simulation), 아스키코드(ASCII)

---

## 2. 문제 설명
두 문자열 `s`와 `skip`, 그리고 자연수 `index`가 주어질 때, 다음 규칙에 따라 문자열을 변환하는 프로그램을 작성해야 합니다.

### 변환 규칙
1. 문자열 `s`의 각 알파벳을 **`index`만큼 뒤의 알파벳**으로 변경합니다.
2. 알파벳을 뒤로 이동할 때, **`skip`에 포함된 알파벳은 제외하고 건너뜁니다.**
3. `z`를 넘어가는 경우, 다시 **`a`로 돌아와서** 이동을 이어갑니다. (순환 구조)

---

## 3. 상세 예시 (시뮬레이션)
예를 들어 `s = "aukks"`, `skip = "wbqd"`, `index = 5`일 때, 첫 번째 글자 `'a'`의 변환 과정은 다음과 같습니다.

* 원래 알파벳 순서대로 `'a'`에서 5만큼 이동하면 `'f'`가 되어야 합니다.
* 하지만 `skip`에 포함된 문자인 `'b'`, `'d'`는 이동 과정에서 카운트하지 않고 건너뜁니다.
  * `a` → `c` (b 스킵, 1단계)
  * `c` → `e` (d 스킵, 2단계)
  * `e` → `f` (3단계)
  * `f` → `g` (4단계)
  * `g` → `h` (5단계)
* 따라서 `'a'`는 `'h'`로 변환됩니다.

---

## 4. 제한 사항
* `s`의 길이: 5 이상 50 이하
* `skip`의 길이: 1 이상 10 이하
* `s`와 `skip`은 알파벳 소문자로만 이루어져 있습니다.
* `skip`에 포함된 알파벳은 `s`에 포함되지 않습니다.
* `index`: 1 이상 20 이하

---

## 5. 입출력 예시

| s | skip | index | result |
| :--- | :--- | :--- | :--- |
| "aukks" | "wbqd" | 5 | **"happy"** |

### 입출력 예 설명
* **'a'**는 `wbqd`를 제외하고 5칸 뒤로 이동하여 **'h'**가 됩니다.
* **'u'**는 `wbqd`를 제외하고 5칸 뒤로 이동하는 과정에서 `z`를 넘어가므로 다시 `a`부터 순환하여 **'a'**가 됩니다.
* **'k'**는 5칸 뒤로 이동하여 **'p'**가 됩니다.
* **'s'**는 5칸 뒤로 이동하여 **'y'**가 됩니다.
* 최종 변환 결과인 **"happy"**를 반환합니다.
