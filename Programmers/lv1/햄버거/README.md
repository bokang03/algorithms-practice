# [Programmers] 햄버거 만들기 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로머스 (Lv. 1)
* **권장 풀이 시간:** 30분
* **핵심 키워드:** 스택(Stack), 배열(Array), 패턴 매칭

---

## 2. 문제 설명
조리실에서 일하는 상수는 전달받은 재료를 정해진 순서대로 쌓아서 햄버거를 만듭니다. 

상수에게 전달되는 재료의 정보를 나타내는 정수 배열 `ingredient`가 주어집니다. 상수가 만드는 햄버거의 정해진 재료 순서는 다음과 같습니다.

* **1:** 빵
* **2:** 야채
* **3:** 고기

상수는 아래와 같은 정해진 순서로 쌓인 재료만을 모아 햄버거 하나를 포장합니다.
> **[빵(1) - 야채(2) - 고기(3) - 빵(1)]**

### 제한 사항
* 재료는 아래서부터 위로 순서대로 쌓입니다.
* 정해진 순서(`1-2-3-1`)가 만들어지는 즉시 해당 재료들은 테이블에서 즉시 제외되고 햄버거 1개로 포장됩니다.
* 중간에 햄버거를 포장하여 빠진 재료들 때문에 새로 정해진 순서가 만들어질 수 있습니다. (예: `1, 2, 1, 2, 3, 1, 3, 1`에서 중간의 `1, 2, 3, 1`이 빠지면 남은 재료들이 합쳐져 다시 `1, 2, 3, 1`이 되어 또 하나의 햄버거를 만들 수 있음)

---

## 3. 입출력 예시

| ingredient | result |
| :--- | :--- |
| `[2, 1, 1, 2, 3, 1, 2, 3, 1]` | **2** |
| `[1, 3, 2, 1, 2, 1, 3, 1, 2]` | **0** |

### 입출력 예 설명
* **첫 번째 예시:** `[2, 1, 1, 2, 3, 1, 2, 3, 1]`에서 3번째 재료부터 6번째 재료까지 `[1, 2, 3, 1]`로 햄버거를 하나 만듭니다. 남은 재료는 `[2, 1, 2, 3, 1]`이 되며, 여기서 다시 `[1, 2, 3, 1]`로 햄버거를 하나 더 만들어 총 2개의 햄버거를 포장할 수 있습니다.
* **두 번째 예시:** 아무리 재료의 순서를 조합해도 `[1, 2, 3, 1]` 순서가 나오지 않으므로 상수는 햄버거를 포장할 수 없습니다.
