# [PCCE 기출문제] 9번 / 지폐 접기

## 문제 요약

지갑 크기 `wallet`과 지폐 크기 `bill`이 주어진다.

지폐는 지갑에 들어갈 때까지 접을 수 있으며, 접는 규칙은 다음과 같다.

- 항상 더 긴 쪽을 반으로 접는다.
- 접은 길이가 소수점이 나오면 버린다.
- 지폐는 그대로 넣거나 90도 회전해서 넣을 수 있다.
- 지폐가 지갑에 들어가면 더 이상 접지 않는다.

지폐를 지갑에 넣기 위해 최소 몇 번 접어야 하는지 구한다.

## 입력

```python
wallet = [지갑의 가로, 지갑의 세로]
bill = [지폐의 가로, 지폐의 세로]
