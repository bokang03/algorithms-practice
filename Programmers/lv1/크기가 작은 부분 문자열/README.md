# [Programmers] 크기가 작은 부분문자열 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 15분
* **핵심 키워드:** 문자열(String), 슬라이딩 윈도우(Sliding Window), 파싱(Parsing), 자료형 범위(Data Type Range)

---

## 2. 문제 설명
숫자로 이루어진 두 문자열 `t`와 `p`가 주어집니다. 문자열 `t`에서 `p`와 **길이가 같은 부분문자열**을 추출했을 때, 그 부분문자열이 나타내는 수가 `p`가 나타내는 수보다 **작거나 같은 것의 개수**를 구하는 프로그램을 작성해야 합니다.

예를 들어, `t = "3141592"`이고 `p = "271"` 인 경우:
* `p`의 길이가 3이므로 `t`에서 길이가 3인 부분문자열들을 추출합니다.
* 추출된 부분문자열: `"314"`, `"141"`, `"415"`, `"159"`, `"592"`
* 이 중 `p("271")`보다 작거나 같은 수는 `"141"`과 `"159"`로 **총 2개**입니다.

---

## 3. 해결 전략 및 주의사항
* `t`의 인덱스를 0부터 `t.length() - p.length()`까지 순회하면서, `p`의 길이만큼 부분문자열을 잘라냅니다(`substring`).
* 잘라낸 부분문자열과 `p`를 숫자로 변환하여 크기를 비교하거나, 문자열 비교(`compareTo`)를 이용해 비교합니다.
* ⚠️ **주의사항 (자료형 범위):**
  * `p`의 길이가 최대 18자리까지 주어질 수 있습니다.
  * 일반적인 32비트 정수형(`int`, 최대 약 10자리)으로 변환하면 **오버플로우(Overflow)**가 발생합니다.
  * 따라서 숫자로 변환할 때는 64비트 정수형(`long` / `long long`)을 사용하거나, 문자열 비교 방식을 활용해야 합니다.

---

## 4. 제한 사항
* `p`의 길이: 1 이상 18 이하
* `t`의 길이: `p`의 길이 이상 10,000 이하
* `t`와 `p`는 숫자로만 이루어진 문자열입니다.

---

## 5. 입출력 예시

| t | p | result |
| :--- | :--- | :--- |
| `"3141592"` | `"271"` | **2** |
| `"500220839878"` | `"7"` | **8** |
| `"10203"` | `"15"` | **3** |

### 입출력 예 설명

* **첫 번째 예시 (`t = "3141592", p = "271"`)**
  * 길이가 3인 부분문자열: `314`, `141`, `415`, `159`, `592`
  * 271 이하인 수: `141`, `159` $\rightarrow$ **2개**

* **두 번째 예시 (`t = "500220839878", p = "7"`)**
  * 길이가 1인 부분문자열 중 7 이하인 수: `5`, `0`, `0`, `2`, `2`, `0`, `3`, `7` $\rightarrow$ **8개**

* **세 번째 예시 (`t = "10203", p = "15"`)**
  * 길이가 2인 부분문자열: `10`, `02`, `20`, `03`
  * 15 이하인 수: `10`, `02(2)`, `03(3)` $\rightarrow$ **3개**
