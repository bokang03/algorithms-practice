# [Programmers] 문자열 나누기 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 20분
* **핵심 키워드:** 문자열(String), 그리디(Greedy), 구현(Implementation), 포인터/카운팅

---

## 2. 문제 설명
문자열 `s`가 주어졌을 때, 아래의 규칙을 따라 문자열을 여러 개로 분해하는 프로그램을 작성해야 합니다.

### 분해 규칙
1. 첫 글자를 읽고, 이 글자를 `x`라고 합니다.
2. 문자열을 왼쪽에서 오른쪽으로 읽어나가면서, `x`와 **같은 글자가 나온 횟수**와 `x`와 **다른 글자가 나온 횟수**를 각각 셉니다.
3. 두 횟수가 **처음으로 같아지는 순간** 스톱하고, 지금까지 읽은 문자열을 분리합니다.
4. 분리된 남은 부분에 대해 1번 과정부터 다시 반복합니다.
5. 더 이상 읽을 글자가 없다면 지금까지 분리된 문자열의 개수를 반환하고 종료합니다.
6. 만약 두 횟수가 같아지지 않은 채로 문자열이 끝나면, 지금까지 읽은 나머지 부분을 하나의 분리된 문자열로 취급하고 종료합니다.

---

## 3. 해결 전략
* 문자열 `s`를 앞에서부터 한 글자씩 순회하며 첫 글자(`x`)를 기준으로 정합니다.
* `same_count`와 `different_count` 두 개의 변수를 활용해 카운팅합니다.
* 순회 도중 `same_count == different_count`가 되는 순간 `answer`를 1 증가시키고 카운터를 초기화하여 다음 글자를 새로운 `x`로 설정합니다.
* 루프가 끝났을 때 카운터가 완전히 초기화되지 않고 남아있다면(마지막 자투리 문자열), `answer`를 1 증가시킵니다.

---

## 4. 제한 사항
* `s`의 길이: 1 이상 10,000 이하
* `s`는 영어 소문자로만 이루어져 있습니다.

---

## 5. 입출력 예시

| s | result |
| :--- | :--- |
| `"banana"` | **3** |
| `"abracadabra"` | **6** |
| `"aaabbaccccabba"` | **3** |

### 입출력 예 설명

* **첫 번째 예시 (`"banana"`)**
  * `x = 'b'`: `b`(1) / `a`(1) $\rightarrow$ 같아졌으므로 `"ba"` 분리 (`answer = 1`)
  * `x = 'n'`: `n`(1) / `a`(1) $\rightarrow$ 같아졌으므로 `"na"` 분리 (`answer = 2`)
  * `x = 'n'`: `n`(1) / `a`(1) $\rightarrow$ 같아졌으므로 `"na"` 분리 (`answer = 3`)
  * 총 **3개**로 분리됩니다.

* **두 번째 예시 (`"abracadabra"`)**
  * `"ab"` / `"ra"` / `"ca"` / `"da"` / `"br"` / `"a"` 로 분리되어 총 **6개**가 됩니다.

* **세 번째 예시 (`"aaabbaccccabba"`)**
  * `"aaabbacc"` / `"ccab"` / `"ba"` 로 분리되어 총 **3개**가 됩니다.
