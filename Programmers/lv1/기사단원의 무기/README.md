# [Programmers] 기사단원의 무기 (Level 1) - 문제 설명

## 1. 개요
* **출처:** 프로그래머스 (Lv. 1)
* **권장 풀이 시간:** 30분
* **핵심 키워드:** 수학(Math), 약수 구하기(Divisors), 시간 복잡도 최적화

---

## 2. 문제 설명
숫자기사단의 각 기사에게는 1번부터 `number`까지의 고유한 번호가 부여되어 있습니다. 기사들은 자신의 번호에 해당하는 **약수의 개수**에 해당하는 공격력을 가진 무기를 구매하고자 합니다.

단, 기사단에는 무기의 공격력에 과도한 불균형이 생기는 것을 막기 위해 **공격력의 제한수치(`limit`)**가 정해져 있습니다. 

### 상세 규칙
1. 각 기사는 자신의 번호의 **약수 개수**만큼의 공격력을 가진 무기를 구매합니다.
2. 만약 약수의 개수가 **`limit`를 초과**하면, 협약에 따라 정해진 **`power`** 공격력을 가진 무기를 구매해야 합니다.
3. 무기를 만들 때 필요한 철의 양은 무기의 **공격력 1당 철 1kg**입니다.
4. 모든 기사단원에게 무기를 만들어 주기 위해 필요한 **총 철의 무게**를 계산해 반환해야 합니다.

---

## 3. 제한 사항
* `number`: 1 이상 100,000 이하 (기사단원의 수)
* `limit`: 2 이상 100 이하 (공격력 제한수치)
* `power`: 1 이상 `limit` 이하 (제한수치 초과 시 대체할 공격력)

### 💡 성능 최적화 핵심
`number`가 최대 100,000이므로, 각 숫자의 약수를 구할 때 1부터 N까지 순회($O(N)$)하는 방식을 사용하면 전체 시간 복잡도가 $O(N^2)$이 되어 시간 초과가 발생합니다.  
따라서 약수를 구할 때는 **제곱근($\sqrt{N}$)까지만 탐색하는 방식**으로 $O(N\sqrt{N})$ 시간 복잡도로 최적화해야 합니다.

---

## 4. 입출력 예시

| number | limit | power | result |
| :--- | :--- | :--- | :--- |
| **5** | **3** | **2** | **10** |
| **10** | **3** | **2** | **21** |

### 입출력 예 설명

* **첫 번째 예시 (`number = 5, limit = 3, power = 2`)**
  * 1번 기사 (약수: 1) $\rightarrow$ 약수 개수: 1
  * 2번 기사 (약수: 1, 2) $\rightarrow$ 약수 개수: 2
  * 3번 기사 (약수: 1, 3) $\rightarrow$ 약수 개수: 2
  * 4번 기사 (약수: 1, 2, 4) $\rightarrow$ 약수 개수: 3
  * 5번 기사 (약수: 1, 5) $\rightarrow$ 약수 개수: 2
  * 약수의 개수가 모두 `limit(3)` 이하이므로 원래 공격력 그대로 사용합니다.
  * 필요한 총 철의 무게: $1 + 2 + 2 + 3 + 2 = \mathbf{10}$

* **두 번째 예시 (`number = 10, limit = 3, power = 2`)**
  * 1~5번 기사의 약수 개수: `1, 2, 2, 3, 2`
  * 6번 기사 (약수: 1, 2, 3, 6) $\rightarrow$ 약수 개수: 4 $\rightarrow$ `limit(3)` 초과로 **power(2)** 적용
  * 7번 기사 (약수: 1, 7) $\rightarrow$ 약수 개수: 2
  * 8번 기사 (약수: 1, 2, 4, 8) $\rightarrow$ 약수 개수: 4 $\rightarrow$ `limit(3)` 초과로 **power(2)** 적용
  * 9번 기사 (약수: 1, 3, 9) $\rightarrow$ 약수 개수: 3
  * 10번 기사 (약수: 1, 2, 5, 10) $\rightarrow$ 약수 개수: 4 $\rightarrow$ `limit(3)` 초과로 **power(2)** 적용
  * 각 기사의 최종 공격력: `1, 2, 2, 3, 2, 2, 2, 2, 3, 2`
  * 필요한 총 철의 무게: $1 + 2 + 2 + 3 + 2 + 2 + 2 + 2 + 3 + 2 = \mathbf{21}$
